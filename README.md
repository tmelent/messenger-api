# messenger-api

## Краткое описание

Пет-проект, разрабатываемый с целью детального изучения технологического стека

## Технологический стек

- Node.JS + TypeScript
- Nest.JS (Express)
- TypeORM
- PostgreSQL
- Socket.IO

### Авторизация

Для авторизации\аутентификации используется библиотека Passport, в частности имплементируются стратегии JWT и Local.
JWT-токен передается как для REST-запросов, так и для WS-запросов.

### Работа с БД

В качестве БД используется PostgreSQL, а взаимодействие с ней осуществляется с помощью TypeORM.
Управление миграциями происходит с помощью TypeORM CLI, в package.json настроены скрипты.

### WebSockets

Управление чатами и сообщениями осуществляется по WebSocket'ам с помощью библиотеки Socket.IO и WebSocketGateway из Nest.JS.

### Валидация данных

Для валидации и преобразования данных к DTO используются пакеты `class-validator` и `class-transformer`

### Тестирование

Тесты пишутся на Jest и покрывают большую часть функционала, но пока находятся в разработке.
